# JAVA-DarkmodeCalculator

A clean, modern calculator built using Java Swing, featuring dark mode UI, smooth operator highlighting, a functional memory system, and accurate arithmetic operations.  

Designed as a simple yet polished desktop application with intuitive behavior — just like a real handheld calculator.

Features:
-----------

### Core Functionality
-----------------------
- Basic arithmetic: Addition, Subtraction, Multiplication, Division
- Decimal support
- Proper operator chaining (e.g., `5 + 3 - 2 * 4 =`)
- Division-by-zero protection

### UI & Experience
--------------------
- Full Dark Mode interface
   
- Large, modern buttons
  
- Highlighted operators when selected
  
- Automatic input reset after result
  
- Prevents accidental concatenation after `=`
  
- Clean, centered layout with responsive GridLayout

###  Memory Operations
-----------------------
Your calculator includes full memory support:
- MC – Clear memory
  
- MR – Recall stored number
  
- M+ – Add current value to memory
  
- C – Clear everything (display, inputs, operator state)

### Smart Input Handling
--------------------------
- Typing after `=` starts a fresh calculation
  
- Switching operators updates state correctly
  
- Prevents multiple decimal points
  
- Clears highlight when done
